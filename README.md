# pswrsh

웹 SSH 클라이언트. 호스트를 저장하고 브라우저 터미널로 접속한다. 운영자 한 명의 로컬 앱이다.

```sh
pnpm install
pnpm dev   # http://127.0.0.1:3000
```

`pnpm dev`는 Next(`127.0.0.1:3000`)와 SSH 게이트웨이(`127.0.0.1:3101`)를 함께 띄운다. 브라우저는 같은 출처의 `/ws`로만 게이트웨이에 닿는다. 포트는 `PORT`, `PSWRSH_GATEWAY_PORT`로 바꾼다.

## 비밀

호스트, 비밀번호, 개인키, 호스트 키 지문은 브라우저 IndexedDB에 하나의 AES-GCM 블롭으로 저장한다. 키는 패스프레이즈에서 PBKDF2-SHA256 600000회로 만들고 메모리에만 둔다. 패스프레이즈를 잊으면 복구할 수 없다.

게이트웨이는 접속 중에만 자격 증명을 메모리로 받고, 디스크와 로그에 쓰지 않는다. 자격 증명은 호스트 키를 수락한 뒤에만 브라우저를 떠난다. 게이트웨이는 이 앱의 출처(`http://127.0.0.1:<PORT>`, `http://localhost:<PORT>`)의 WebSocket만 받는다. 터널로 열 때도 같은 포트를 써야 한다.
